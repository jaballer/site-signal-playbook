---
order: 6
title: Review & renew
when: each quarter
checklist:
  - Compare results with the 90-day targets and the original opportunity model
  - Re-benchmark competitors and re-run the full prompt set
  - Re-score the audit pillars that changed
  - Review the brand-term list, keyword set and prompt set, and version any changes
  - Revise the roadmap and opportunity model with what the quarter taught
  - Propose scope changes with the revenue case for each
deliverables:
  - Quarterly review deck
  - Next-quarter roadmap
  - Renewal or expansion proposal
---

The quarterly review resets the plan with leadership. It's where the program is renewed, expanded or corrected, so it's argued in pipeline and competitive position, not tasks completed. How to prepare and run it, and the signs an account is drifting before anyone says so, are in [Renewal](page:renewal).
