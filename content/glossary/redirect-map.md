---
term: Redirect map
definition: The list pairing every URL on an old site with its closest equivalent on the new one, used to route visitors and search engines through a migration without losing the value the old URLs earned.
signals:
  - migration-risk
questions:
  - crawler-readiness
related:
  - canonical
  - migration
---

The most common failure isn't a missing map, it's a map that covers the navigation and misses the resource library, which is usually where the links and the non-branded traffic were.
