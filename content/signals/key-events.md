title: Key event definitions
layer: integrity
phases:

question: Do the conversions we report mean something?
definition: Which GA4 events are marked as key events, and whether event names are consistent.
source: GA4 Admin
capture: Mark only real conversions and record the definitions in the engagement record.
read: No near-duplicate names, and no clicks marked as key events
---

Marking a key event isn't retroactive, and renaming one mid-program breaks the trend. Decide in the baseline phase and leave it.
